# Probes behind CHANGE-BRIEF.md

Claude Code ran these on 2026-11-12, while drafting the brief at my request, so that its timing predictions and predicted failures rest on what Godot 4.7.2 does on this machine rather than on the documentation alone.

**How they were run.** The files in `tests/` were copied into `game/tests/` of a scratch copy of this folder's `game/`, imported once, and run headless at `--fixed-fps 60` or `30`; the environment variable `PROBE_MODE` picks the case. They are not in `game/`. The slash probe is a scene, because `rudy.gd` names the `Sfx` autoload, which a `--script` run cannot compile against. Godot 4.7.2 (`v4.7.2.stable.official.ed1daf0bf`), macOS, 60 physics ticks per second (the project sets none, so the default holds).

| Probe | What it does | What it showed | Logs |
|---|---|---|---|

**What this changes in the course's warnings.** The assignment says a clip written with `loop = true` "doesn't loop and may load without complaint." In 4.7.2 it loops: the old name is mapped. The `loop_mode` read-back check still matters, because a clip can carry the wrong `loop_mode` for other reasons, but the Godot 3 name is not one of them here. `playback_speed` is the trap that is real.
